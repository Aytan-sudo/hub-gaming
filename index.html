      📲 Protège les passeports : installe l’app

      Dans Safari, les données d’un site peuvent s’effacer après 7 jours sans visite. L’app de l’écran d’accueil garde les siennes, mais elle ne voit pas celles de Safari : il faut les y transférer.

      1. Exporte la sauvegarde avec le bouton ci-dessous.
      2. Dans Safari : Partager (parfois dans le menu •••), puis « Sur l’écran d’accueil ».
      3. Dans l’app : Espace administrateur, puis « Choisir une sauvegarde ».

      Ce passeport est enregistré dans ce navigateur, sur cet appareil. Une copie de secours peut en être exportée depuis l’Espace administrateur.

      Espace administrateur

      Les objectifs sont souples. Les tampons gagnés et le niveau de la mascotte restent acquis après une absence.

      Activités qui valident une journée

      Une seule journée est comptée par date, quel que soit le nombre de jeux. Les changements s’appliquent aux prochaines validations.

      Sauvegarder les passeports

      Le fichier contient tous les profils, leurs tampons et les données des jeux raccordés. Garde-le dans les fichiers de l’appareil ; une copie ailleurs protège aussi contre sa perte.

      Sauvegarde prête à restaurer

      Cette restauration remplace le coffre actuel. Exporte-le d’abord si tu veux conserver sa progression récente. Les onglets de jeu déjà ouverts devront être rouverts.

      Cette protection dépend du navigateur et ne remplace pas le fichier de sauvegarde.

      Anciennes parties

      Les données antérieures aux profils sont conservées en mode invité. Tu peux les copier vers le profil choisi, sans écraser ses données existantes. Pour Multiplication, les révisions sont reprises lorsque le prénom correspond exactement.

      Gestion des profils

      Un profil archivé est masqué, mais ses données sont conservées et restent dans les sauvegardes.
